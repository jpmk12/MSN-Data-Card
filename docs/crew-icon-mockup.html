Crew icon — options for any crew

Today the icon beside each name is hard-coded per callsign (DEAD's skull, DUFF's clover), so it only works for that crew. Here are four directions to make it universal. Nothing below is wired into the app yet — just mockups to pick a direction.
Option A

Auto monogram avatars

A colored disc with the callsign's initials, generated automatically and colored from the name. Zero setup, works for anyone, and updates as you type.

Best default — no picking required, never blank.
Option B

Pick-an-icon

Tap the icon to choose from a small aviation set (helmet, wings, jet, skull, star, shield, bull, clover…). Each seat remembers its pick.
